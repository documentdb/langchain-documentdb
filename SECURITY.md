# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests. Follow the private reporting instructions in the
[DocumentDB security policy](https://github.com/documentdb/documentdb/security/policy).

Include the affected integration, commit or version, impact, reproduction
steps, and any known mitigations. Do not include production credentials,
account identifiers, or customer data.

## Supported versions

The packages in this repository are pre-release and unpublished. Security fixes
are applied to the default branch until versioned releases are available.
